# Электронная библиотека — вариант 4

**Сергеев Никита Андреевич, группа 241-372**

Flask-приложение для каталога книг, рецензий и истории просмотров.

## Запуск локально

Из папки `Лаба 7`:

```powershell
python -m venv ve
ve\Scripts\activate
pip install -r requirements.txt
python seed_demo.py
python -m flask --app app run
```

Откройте <http://127.0.0.1:5000/>. Демо-инициализатор создаёт SQLite базу,
6 жанров, 12 книг с обложками, 14 рецензий, историю просмотров и пользователей
трёх ролей. Его можно запускать повторно: существующие тестовые данные не
дублируются.

## Демо-входы

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `Admin123` |
| Модератор | `moderator` | `Mod12345` |
| Пользователь | `reader` | `User123` |
| Пользователь | `reader2` | `User234` |

Администратор управляет книгами и открывает статистику. Модератор может
редактировать книги и скрывать/публиковать рецензии. Пользователи могут оставлять
по одной рецензии на книгу.

## Функциональность варианта 4

- На главной странице есть пять популярных за последние три календарных месяца
  книг и пять недавно просмотренных книг текущего пользователя или браузера.
- Просмотры фиксируются автоматически при открытии страницы книги; для одной
  книги и одного пользователя сохраняется не более 10 просмотров за день.
- Администратору доступна статистика: журнал просмотров и агрегированное число
  просмотров книг только аутентифицированными пользователями.
- Журнал и статистика постраничные (по 10 строк). Для обеих вкладок можно
  выгрузить все результаты в CSV. В статистике книг работает включительный
  фильтр по датам.

Описание книги и рецензии поддерживают Markdown; HTML очищается перед показом.
Обложки хранятся в `instance/covers`, а сведения о них — в отдельной таблице.
