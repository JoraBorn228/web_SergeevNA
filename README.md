### Лаба 3 — Flask: сессии, аутентификация (Flask-Login)
Путь: `Лаба 3/`

**Что реализовано:**
- `/counter` — «Счётчик посещений»: число посещений хранится в глобальном объекте
  `session`, поэтому у каждого пользователя/браузера своё значение
- `/login` — форма входа (логин, пароль, чекбокс «Запомнить меня»):
  - пользователь `user` с паролем `qwerty`
  - при успешном входе — редирект на главную с сообщением об успехе
  - при ошибке — остаёмся на странице входа с сообщением о неверных данных
  - чекбокс «Запомнить меня» устанавливает `remember_token` (срок хранения 30 дней)
- `/logout` — выход из системы
- `/secret` — «Секретная страница», доступна только через `@login_required`:
  - ссылка в навбаре видна только аутентифицированным пользователям
  - анонимного пользователя перенаправляет на `/login?next=/secret`
    с сообщением о необходимости аутентификации
  - после входа происходит автоматический возврат на запрошенную страницу
- Навбар со ссылками на все страницы; блок «Войти/Выйти» зависит от статуса
- **21 тест** в `tests/test_app.py`

### Лаба 4 — Flask: CRUD учётных записей пользователей (SQLite)
Путь: `Лаба 4/`

**Что реализовано:**
- БД на SQLite: таблицы `users` (id, логин, хеш пароля, фамилия, имя, отчество,
  роль, дата создания) и `roles` (id, название, описание)
  - дата создания проставляется автоматически (`DEFAULT datetime('now')`)
  - фамилия и роль могут отсутствовать (NULL)
- **Аутентификация** (Flask-Login, как в ЛР №3), но пользователь загружается из БД
- **Главная** (`/`) — таблица пользователей: №, ФИО, название роли, действия
  - кнопки «Редактирование»/«Удаление» и «Создание пользователя» — только для
    аутентифицированных; «Просмотр» — для всех
- **Просмотр** (`/users/<id>`) — данные пользователя в виде таблицы (доступен всем)
- **Создание** (`/users/create`) — форма (логин, пароль, фамилия, имя, отчество,
  селектор роли), доступ только после входа; при ошибке — flash + заполненная форма
- **Редактирование** (`/users/<id>/edit`) — та же форма-макрос без полей логина и
  пароля, предзаполнена данными
- **Удаление** (`POST /users/<id>/delete`) — через модальное окно Bootstrap
  «Вы уверены, что хотите удалить пользователя {ФИО}?» с кнопками «Да»/«Нет»
- **Смена пароля** (`/change-password`) — старый/новый/повтор, ссылка в навбаре
- **Серверная валидация**: логин (латиница+цифры, ≥5), пароль (8..128, регистр,
  цифры, допустимые символы, без пробелов), обязательные поля; подсветка
  `is-invalid` + `invalid-feedback`
- Форма вынесена в макрос `templates/_macros.html` (используется на создании и
  редактировании)
- **46 тестов** в `tests/test_app.py`
